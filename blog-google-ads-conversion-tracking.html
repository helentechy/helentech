Google Ads Conversion Tracking: Set It Up Before You Spend

By HelenTech•14 October 2026•5 min read
Home/Blog/Article

Key takeaways

  • Track the actions that matter: calls, forms, messages and purchases.
  • Count each action once. Double counting makes results look better than they are.
  • Test every conversion action before you rely on the numbers.
  • Tracking is the first step. It does not guarantee results by itself.

Many Google Ads accounts spend money without a clear way to see what that spend produced. Conversion tracking fixes that. It records valuable actions after someone clicks your ad, so you can see which campaigns, keywords and ads lead to enquiries or sales.

Why it matters

Reports that only show clicks do not tell you if the clicks were useful. Conversion data also helps Google's automated bidding learn what a good result looks like for your business, so poor tracking can lead to poor optimization.

What to track

  • Contact form submissions.
  • Phone calls and call button clicks.
  • WhatsApp or chat clicks.
  • Purchases, with the order value.
  • Bookings or quote requests.

Common ways to set it up

You can create conversion actions with the Google tag or Google Tag Manager, or import key events from Google Analytics 4. Choose one method for each action so it is not counted twice. If you sell online, pass the purchase value as well so reports show revenue, not only order counts.

Common mistakes

  • Counting every page view as a conversion.
  • Counting the same action twice, for example from both Google Ads and an imported GA4 event.
  • Using a thank-you page that people can reach without completing the action.
  • Not recording a value for purchases.
  • Never testing, so a broken tag goes unnoticed.

Test before you rely on it

  1. Complete a real test action, such as submitting your own form.
  2. Use Google's tag testing tools to confirm the tag fired.
  3. Check that the conversion action shows as recording in Google Ads.
  4. Repeat after any website change that touches forms or checkout.

Next step

Once tracking is reliable, you can review search terms, adjust bids and budgets, and pause what is not working. If you would like your tracking set up and checked before more budget goes in, we can help.
